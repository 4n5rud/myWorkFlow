# 장애 패턴 노트

> 문제를 해결할 때마다 세 줄을 맨 위에 더한다(가장 최근이 위). 스택이 바뀌어도 다음 프로젝트에서 같은 문제를 빨리 좁히려는 기록이다.
> 이 파일의 원본은 하네스 저장소의 `learning/`이고, 노트 보관함의 `학습/`에 사본이 맞춰진다(`sync-guides.sh`). 규칙은 지침서 `00 세션 공통 지침.md` §16.

형식:

```
## YYYY-MM-DD <프로젝트> <한 줄 제목>
- 계층: 네트워크 / 인증 / 빌드와 배포 / 데이터 / 코드 / 외부 연동 / 설정 가운데 하나
- 원인: 확인한 원인 한 줄(추정이면 추정이라고)
- 패턴: 다음에 비슷한 증상을 보면 먼저 확인할 것 한 줄
```

---

## 2026-11-16 하네스 설치 스크립트가 지침서 13개를 덮어씀
- 계층: 설정(운영체제 권한)
- 원인: macOS 개인정보 보호가 노트 보관함 폴더 읽기를 막자 `ls`가 실패했고, 스크립트가 그 실패를 "빈 폴더"로 해석해 사본으로 덮어씀
- 패턴: "없음"과 "못 읽음"을 구분한다. 명령이 실패했는지 결과가 비었는지를 따로 확인하고, 못 읽으면 아무것도 쓰지 않는다

## 2026-11-09 서브모듈과 작업 폴더의 모든 커밋이 "읽기 전용 저장소"로 막힘
- 계층: 빌드와 배포(git 훅)
- 원인: git이 훅에 넘기는 환경 변수 GIT_DIR이 다른 저장소를 묻는 명령에 새어 들어가, 모든 저장소가 같은 저장소로 보임
- 패턴: 훅이나 스크립트가 다른 저장소를 볼 때는 상속받은 환경 변수를 지우고 실행한다. 시험은 스크립트 직접 호출만이 아니라 실제 git 명령으로도 돌린다

## 날짜 미상 백엔드에서 한국 날짜가 하루 전으로 저장됨
- 계층: 데이터(시간대)
- 원인: 한국 자정을 UTC로 바꾼 시각을 문자열로 잘라 날짜를 만들어 언제나 전날이 됨
- 패턴: 날짜 버그는 "언제 기준 시각인가(UTC, KST)"부터 확인한다. 자를 때는 오프셋을 더한 뒤 자른다(지침서 06)
