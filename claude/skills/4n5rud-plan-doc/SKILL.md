# 왼쪽 목차 문서 만들기

인자: $ARGUMENTS (주제. 정리할 내용이나 자료를 함께 줄 수 있다)

## 이 스킬이 정하는 것과 정하지 않는 것
- **정하는 것은 화면 틀뿐이다.** 왼쪽에 목차, 오른쪽에 내용, 화이트와 블랙 고르기, 표와 인용 모양. 틀은 `{{HARNESS_DIR}}/templates/기획서 양식.html`이다.
- **장 구성은 정하지 않는다.** 장의 이름, 순서, 개수는 가진 내용과 사용자가 원하는 것에 맞춘다. 정해진 장 목록을 채우지 않는다.
- 🔴 **없는 정보를 지어내지 않는다.** 근거가 없는 장은 만들지 않는다. 빈칸을 채우려고 일정, 크기, 사용자, 규칙, 결정 사항을 만들어 넣지 않는다. 모르는 것은 "확인 필요"로 쓰거나 사용자에게 묻는다(2026-11-10 사용자 지적: 장마다 쓸 내용을 정해 두었더니 세션들이 없는 정보를 지어냄).

## 만드는 법
1. 사용자가 준 내용, 자료, 대화에서 실제로 있는 정보만 모은다. 코드나 문서에서 확인한 것과 추정은 나눈다(추정이면 문장 끝에 "(추정)").
2. 모은 내용을 묶어 장(`<h2>`)을 정한다. 사용자가 장 구성을 말했으면 그대로 따른다.
3. 틀을 복사해 `<main>` 안에 `<h1>` 제목과 `<h2>`, `<h3>`로 쓴다. 왼쪽 목차는 `<h2>`에서 저절로 만들어진다. 표, 인용, 목록은 내용에 필요할 때만 쓴다.
4. 문장은 4n5rud-guides 스킬의 `05 쇠맛 줄이기.md`와 `17 기술 문서 쓰기.md`(기획서는 기술 문서)를 따른다. 절대 경로와 개인 노트 위치를 쓰지 않는다.
5. 다 쓴 뒤 틀의 주석을 지우고 `grep -n '{{' <파일>`로 남은 자리가 없는지 본다. 화이트, 블랙 단추와 목차 스크립트는 남긴다.

## 저장과 보고
- 사용자가 위치를 말하지 않으면 노트 보관함 `{{NOTES_DIR}}/work/<프로젝트>/<문서 종류>_<주제 붙여 쓰기>_<YYYYMMDD>.html`에 저장한다. 같은 이름이 있으면 덮어쓰지 않고 묻는다. 저장한 뒤 `open`으로 연다.
- 보고: 파일 위치, 장 목록, 근거가 없어 쓰지 않았거나 "확인 필요"로 둔 것.
